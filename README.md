## 🚀 Featured Projects

### 💰 FinAgent: AI-Powered Finance Management App
A finance management application with an AI agent (powered by the **Groq API**) that answers finance-related queries. Includes automated email reminders, a spending dashboard, and financial plan creation. Built as a collaborative team project.

### 🫁 Pneumonia Detector: Chest X-Ray Screening with Deep Learning
Trained and benchmarked **8 CNN architectures** (ResNet, DenseNet, EfficientNet, VGG, Inception, MobileNet, and a custom CNN) using transfer learning in **PyTorch**, reaching up to **0.98 test AUC**. The best model is deployed behind a **FastAPI** backend with a **React** frontend for real-time X-ray upload and screening.

`PyTorch` `FastAPI` `React` `Transfer Learning`

### 🔐 SecureAuth: AI-Powered Multi-Factor Authentication
A **Flask** MFA system with **bcrypt** hashing, **OpenCV/LBPH** face recognition, and **blink-based liveness detection** to block photo-spoofed logins. Includes a pandas/matplotlib dashboard that visualizes login analytics and flags anomalies.

`Flask` `OpenCV` `bcrypt` `pandas` `matplotlib`
